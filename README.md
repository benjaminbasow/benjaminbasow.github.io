# Benjamin Basow Academic Website

This is a simple static website designed for GitHub Pages.

## Publish it

1. Sign in to GitHub.
2. Create a new PUBLIC repository named exactly:

   `benjaminbasow.github.io`

3. Upload `index.html` and `styles.css` to the root of the repository.
4. Open the repository's **Settings**.
5. Choose **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)` folder.
8. Save.

Your website should then be available at:

`https://benjaminbasow.github.io`

## Customize next

Replace the placeholders in `index.html` for:

- Email address
- LinkedIn URL
- CV PDF
- Working paper PDFs
- Replication/code links
- Optional professional headshot

For the CV, add your PDF to the repository, for example:

`Benjamin_Basow_CV.pdf`

Then change the CV link in `index.html` from:

`href="#"`

to:

`href="Benjamin_Basow_CV.pdf"`
